## oms test list

List the available tests and playlists

### Synopsis

List the tests that can be run against a Codesphere installation and the playlists that group them.

```
oms test list [flags]
```

### Examples

```
# List the available tests and playlists
$ oms test list

```

### Options

```
  -h, --help   help for list
```
